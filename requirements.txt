# audioviz — pełny, przypięty zestaw zależności Pythona (3.11+, Windows/Linux).
# Wygenerowany z działającego .venv: runtime + zależności pośrednie.
#
# Instalacja:
#   uv venv .venv --python 3.11
#   uv pip install --python .venv/Scripts/python.exe -r requirements.txt
# (albo po prostu: ./setup.ps1)
#
# Kluczowe pakiety: audio-separator (Demucs), onnxruntime, torch, torchaudio,
# librosa, soundfile, numpy, scipy. audio-separator bez onnxruntime/torchaudio
# instaluje się, ale pada przy imporcie — dlatego są tu jawnie.
#
# GPU: pin `torch==2.15.0` z PyPI to wheel CPU (`+cpu`) i audio-separator po cichu
# liczy na procesorze. Na maszynie z NVIDIA po instalacji tego pliku dołóż build
# CUDA (sm_120/Blackwell wymaga CUDA 12.8+, tu sprawdzone cu130):
#   uv pip install --python .venv/Scripts/python.exe \
#       --index-url https://download.pytorch.org/whl/cu130 torch==2.14.0+cu130
# `setup.ps1` robi to automatycznie, gdy wykryje nvidia-smi (pomiń: -SkipGpu).
# torchaudio 2.11.1 (+cpu) działa z tym buildem — nie trzeba go ruszać.
#
# Pobieranie utworów z sieci (panel na stronie głównej): yt-dlp ściąga audio,
# ffmpeg składa z niego WAV. yt-dlp jest w tym pliku; ffmpeg trzeba mieć w PATH
# (winget install Gyan.FFmpeg / brew install ffmpeg). Bez ffmpeg panel pokaże
# „pobieranie brak” zamiast się wywalać w połowie roboty.
